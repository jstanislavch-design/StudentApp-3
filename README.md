# Лабораторная работа №2 — Hibernate ORM

## Описание
Приложение для управления студентами с использованием Hibernate ORM и базы данных PostgreSQL.

## Технологии
- Java 17
- Hibernate ORM
- PostgreSQL
- Maven

## Как запустить
1. Клонировать репозиторий
2. Настроить PostgreSQL базу данных
3. Указать данные БД в `hibernate.cfg.xml`
4. Запустить `Main.java`

## Функции
- Добавление студента
- Получение всех студентов
- Обновление данных студента
- Удаление студента
